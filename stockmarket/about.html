About This Project

This StockMarketPro website is a mini project created using only HTML and CSS. The main focus is on using different CSS selectors in a meaningful, real-world theme.

You can explain concepts like: what is a stock, what are indices like NIFTY and SENSEX, and how investors track markets.

You can extend this by: adding JavaScript, live APIs for real-time prices, or interactive charts later.
